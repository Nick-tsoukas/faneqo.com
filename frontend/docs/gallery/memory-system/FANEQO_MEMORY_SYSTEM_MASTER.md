# Memory System — master

Constitution for the Gallery Doorway + Memory Deck lab. Not production.

---

## Identity

A concert disappears. The photograph remains.

Living Gallery is not concert-only. A Gallery may be a show / Night, tour, backstage, studio, release, artist collection, or other photographic memory. Context tells the truth of the collection. No fabricated show identity.

---

## Product test

Does this belong to the artist's world?  
Can I understand the Gallery immediately?  
Does the Deck feel like a finite physical collection?  
Does the same photograph travel Deck → Living Gallery → Deck?
